【一、这是什么】
────────────────────────────────────────────
本目录安装的是 Sparrow Wallet 2.5.4（Windows 桌面版，jpackage 结构，
主程序为 Sparrow.exe）。原版软件没有多语言支持，界面文字 100% 硬编码
在程序内部（31 个界面布局文件 FXML + 400 余个 Java 类中）。

本次已对程序做「完整中文汉化」，并直接安装到本目录，同时留下可回滚的
补丁包与还原脚本，方便随时还原英文版或在字典中追加新翻译。

────────────────────────────────────────────
【二、如何使用】
────────────────────────────────────────────
1. 启动：直接双击运行  C:\Software\Sparrow\Sparrow.exe
   —— 启动后即为中文界面（菜单：文件/视图/工具/帮助；
      欢迎页：新建钱包/打开钱包/导入钱包/拖拽文件以打开；
      状态栏、全部对话框、设置、交易、UTXO、多签、硬件钱包导入向导等均已汉化）。

2. 补丁包位置：C:\Software\Sparrow\中文补丁\
   ├─ patch\modules.patched     汉化后的运行时镜像（jimage 文件，89,890,740 字节）
   ├─ patch\翻译字典\*.json     全部翻译字典（FXML + Java 六批，可扩展）
   ├─ patch\脚本\*.py           汉化管线脚本（类改写、镜像重建、校验）
   ├─ backup\modules.original   原始英文镜像备份（回滚基线）
   ├─ 应用补丁.ps1               一键重新应用中文补丁
   ├─ 还原.ps1                   一键还原原始英文版
   └─ 安装说明.md                详细说明文档

3. 重新应用补丁（例如误还原之后）：
   右键“应用补丁.ps1” → 使用 PowerShell 运行
   （或命令行：powershell -ExecutionPolicy Bypass -File "应用补丁.ps1"）
   脚本会自动结束正在运行的 Sparrow、备份原版、安装汉化镜像。

4. 还原英文版：
   右键“还原.ps1” → 使用 PowerShell 运行，脚本会用原始镜像恢复。

5. 验证汉化是否生效：
   - 界面直接可见中文；
   - 镜像 SHA256 应等于 95B294A9010C58E962FC20EFE55BF4ACF0DC603E294989BC860AEFDDDA30DBBB
     （校验命令：certutil -hashfile "runtime\lib\modules" SHA256）

【便携版说明（重要）】
────────────────────────────────────────────
本版本已做成“便携版（绿色版）”——**放到任意目录、任意路径都能直接
汉化并运行**，与安装位置无关：

· 整个程序（Sparrow.exe + app + runtime）与“中文补丁”目录、本说明
  放在一起即可使用，移动、复制到其他电脑、其他盘符均无需重装。
· 程序镜像内部不含任何绝对路径，配置（Sparrow.cfg / release /
  .jpackage.xml）也没有路径依赖；“应用补丁.ps1”“还原.ps1”已改为
  相对路径，自动定位脚本所在目录的上一级为程序根目录。
· 已实测：把程序复制/解压到带空格的陌生路径（如 C:\Users\Public\
  便携测试 Sparrow）后直接启动，中文界面完整生效。
· 分发方式：把整个目录打包成 zip（根目录已提供
  “Sparrow-2.5.4-中文便携版.zip”），别人解压后双击 Sparrow.exe
  即可使用，无需安装、无需联网、无需额外环境。
· 钱包数据保存在用户目录（C:\Users\<用户名>\AppData\Roaming\
  Sparrow\），不随程序目录移动；若要在另一台电脑继续使用钱包，
  请一并复制该目录下的 wallets 文件夹。
· 若某台电脑运行“应用补丁.ps1/还原.ps1”时提示执行策略限制，用
  powershell -ExecutionPolicy Bypass -File "脚本名.ps1" 运行即可。

[事件 1] 确认版本与结构
  用户提供 GitHub 仓库链接（github.com/sparrowwallet/sparrow）并委托汉化。

[事件 4] Java 字面量翻译（六批字典，853 → 2330 条）
  编写类文件常量池改写器 apply_java_trans.py：只替换常量池中未被

  六批字典人工审定：
    · 第一批 base（853 条）：主界面、对话框、设置、交易等高频词
    · 第二批 batch2（+660 条）：扫描残留后补翻

[事件 5] 镜像重建路线探索（一条路线被证伪）

【六、常见问题】
────────────────────────────────────────────
1. 启动 Sparrow.exe 后窗口一闪而过/无界面？
   → 多为残留锁文件导致（程序单实例机制）。删除
     C:\Users\<用户名>\AppData\Roaming\Sparrow\sparrow.lock
     后重新启动即可。

2. 如何追加新翻译？
   → 编辑 中文补丁\patch\翻译字典\java_trans_all.json
     （“英文原文”: “中文译文” 结构），然后按序运行：
     脚本\apply_java_trans.py → 脚本\rebuild_jimage.py → 应用补丁.ps1。
     注意：与外部值比较的字符串不可翻译（详见安装说明.md），
     以免破坏过滤、排序、协议判断等功能。

3. 想恢复英文原版？
   → 运行 中文补丁\还原.ps1，或手动用
     中文补丁\backup\modules.original 覆盖 runtime\lib\modules。

4. 日志里的汇率 WARN？
   → 属正常现象（汇率服务需联网，当前网络不可达），不影响任何功能。
