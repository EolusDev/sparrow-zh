# Sparrow 中文补丁 — 使用与构建说明

本补丁为 **Sparrow Wallet（Windows 桌面版，jpackage 结构）** 提供完整中文化，
以 **v2.5.4** 为基准制作；构建工具链与版本号无关，亦可用于后续版本的重新汉化。

---

## 一、汉化内容

| 项目 | 说明 |
|---|---|
| 主界面菜单 | 文件 / 视图 / 工具 / 帮助 全中文 |
| 欢迎页 | 新建钱包 / 打开钱包 / 导入钱包 / 拖拽文件以打开 |
| 状态栏 | 未连接（点击右侧开关进行连接）等状态信息 |
| 主要对话框 | 钱包创建/打开/密码、账户导入导出、多签、交易、UTXO、设置、服务器、PayNym、消息签名、私钥清扫、助记词等 |
| FXML 界面 | 31 个布局文件，其中 27 个被改写（约 2700+ 中文字符） |
| Java 字面量 | 最终字典 2359 条，应用覆盖 439 个类、2444 处字符串 |
| 成品镜像 | 477 个资源含中文、共 20481 个中文字符；57359 个资源完美哈希 0 失配 |

> **术语口径**：Bitcoin / Taproot / Segwit / UTXO / PayNym / RBF / CPFP / PSBT /
> BIP39 / BIP32 / Tor / Electrum / Payjoin / Coldcard / Testnet 等专名保留英文；
> Address / Balance / Status / Send / Receive / Settings 等通用词译为中文。
>
> **有意保留英文**：SQL 语句、日期/格式串、颜色/CSS、与外部值比较的错误串
> （Tor / 服务器 / 协议诊断 / 硬件卡底层协议错误 / 服务端日志）。这些内容不参与
> 界面展示，保留英文可避免误译破坏功能，也便于对照上游排查。

## 二、三种使用方式

### 方式 A：中文便携版（普通用户）
直接使用 Releases 的 `Sparrow-中文便携版.zip`，解压后双击 `Sparrow.exe`，免安装、免环境。

### 方式 B：双击「一键汉化.bat」（给本机已装的英文 Sparrow 打补丁）
1. 安装 [Python 3.8+](https://www.python.org/downloads/)，安装时勾选 **Add Python to PATH**。
2. 双击 `中文补丁\一键汉化.bat`。
3. 按提示把 Sparrow 安装文件夹拖入窗口（或回车自动探测），并选择是否直接装回。
4. 首次会在镜像旁生成 `modules.original.bak`（原始英文版，用于还原）。

### 方式 C：命令行 `build.py`（进阶 / 跨版本 / 开发者）
```bash
# 对已安装的 Sparrow 构建并装回
python 中文补丁/patch/脚本/build.py --src "D:\Sparrow" --install

# 只产出汉化镜像，不改动安装
python 中文补丁/patch/脚本/build.py --modules "原modules路径" --out modules.zh
```
参数：`--work` 指定工作目录，`--clean` 清空重建，`--install-to` 装回到另一个 Sparrow 目录。

`build.py` 自动执行：**纯 Python 解包 jimage → 应用 FXML 字典 → 应用 Java 字典 →
就地重建镜像 → 完美哈希 + 中文统计校验**。**全程只用 Python 标准库，无需安装 JDK。**

## 三、目录结构

```
中文补丁/
├── 一键汉化.bat            # 双击入口（方式 B）
├── 应用补丁.ps1 / 还原.ps1  # PowerShell 装回 / 还原
├── 安装说明.md             # 本文件
├── patch/
│   ├── 翻译字典/            # fxml_trans.json + 8 个 java_trans 分批字典（构建时自动合并为 2359 条）
│   └── 脚本/
│       ├── build.py            # ★ 一键编排
│       ├── jimage_extract.py   # 纯 Python 解包 jimage（替代 JDK jimage extract）
│       ├── jimage_parse.py     # jimage 解析 / 完美哈希
│       ├── apply_fxml_trans.py # FXML 翻译
│       ├── apply_java_trans.py # Java 常量池字面量翻译（不动标识符）
│       ├── rebuild_jimage.py   # 就地重建 jimage
│       └── scan_remaining.py   # 扫描残留英文，辅助增量翻译
└── backup/modules.original # 原始英文镜像（回滚基线）
```

## 四、还原英文版

- 双击 `还原.ps1`，或
- 把 `runtime\lib\modules.original.bak` 改名回 `modules`（先退出 Sparrow）。

---

## 五、增量翻译 / 升级到新版 Sparrow

工具链与版本无关，新版无需逆向重做：

1. 拿到新版原版 `runtime\lib\modules`，对其运行 `build.py`（现有字典自动沿用）。
2. 运行 `scan_remaining.py` 列出仍残留的英文字面量。
3. 把**界面可见**的新文案补进 `翻译字典\` 下对应的分批字典（FXML 文案补 fxml_trans.json），
   结构为 `"英文原文": "中文译文"`；构建时 build.py 自动按固定顺序合并全部字典，并强制
   剔除“外部比较串黑名单”（节点/协议错误原文，保留英文以维持错误匹配）。
4. 重跑 `build.py` 即可。脚本幂等，可反复运行。

### 哪些字符串不能翻译（重要）
- 与**外部值**比较/判断的串：协议错误码、服务器返回、过滤排序键、SQL、CSS、日期格式。
  一旦翻译会导致判断失效、过滤排序异常。
- 类名、方法名、字段名、描述符等标识符（改写器会自动跳过，无需手工区分）。
- 仅在日志/异常里出现、需要对照上游文档的英文诊断信息。
- 判别看不准时，宁可保留英文；界面按钮/菜单/提示/列标题等用户可见文本才翻译。
  内部自比较的可见串（如按钮状态 Show/Hide）需保证比较两端同时被替换，改写器按字面量
  统一替换，天然成对，不要只改其中一处来源。

## 七、已知限制

- 硬件卡底层协议错误、Electrum / Bitcoin Core 服务端日志、Tor 底层错误保留英文（仅日志场景）。
- 汇率模块需联网，离线时日志出现 WARN 属正常，不影响功能。
- 汉化只改界面显示文字，不改钱包数据与任何加密/签名逻辑；正式使用前仍请备份钱包。
