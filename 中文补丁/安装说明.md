# Sparrow 2.5.4 完整中文补丁 — 使用说明

本补丁为 **Sparrow Wallet 2.5.4（Windows 桌面版，jpackage 结构）** 提供完整中文化。
已实际安装到 `C:\Software\Sparrow` 并验证可用。

---

## 一、补丁已包含的内容

| 项目 | 说明 |
|---|---|
| 主界面菜单 | 文件 / 视图 / 工具 / 帮助 全中文 |
| 欢迎页 | 新建钱包 / 打开钱包 / 导入钱包 / 拖拽文件以打开 |
| 状态栏 | 未连接（点击右侧开关进行连接）等状态信息 |
| 主要对话框 | 钱包创建/打开/密码、账户导入导出、多签、交易、UTXO、设置、服务器、PayNym、消息签名、私钥清扫、助记词等 |
| FXML 界面 | 31 个界面布局文件全部中文化（约 2700+ 中文字符） |
| Java 字面量 | 2330 条翻译字典（六批人工审定），应用覆盖 470+ 个类、约 3500 处字符串 |

> 术语口径：Bitcoin / Taproot / Segwit / UTXO / PayNym / RBF / CPFP / PSBT / BIP39 /
> BIP32 / Tor / Electrum / Payjoin / Coldcard / Testnet 等专有名词保留英文；
> Address / Balance / Status / Send / Receive / Settings 等通用词译为中文。
>
> 有意保留英文的部分：SQL 语句、日期/格式串、颜色/CSS、与外部值比较的错误串
> （Tor / 服务器 / 协议诊断 / 硬件卡底层协议错误 / 服务端日志消息）。
> 这些保留英文更利于故障排查，避免误译造成功能异常。

```
C:\Software\Sparrow\中文补丁\
├── patch\

├── 还原.ps1                  ← 一键还原原始英文版
└── 安装说明.md               ← 本文件
```

## 三、使用方法

### 已安装状态
当前 `C:\Software\Sparrow\runtime\lib\modules` 已装汉化镜像，直接启动
`C:\Software\Sparrow\Sparrow.exe` 即为中文界面。

### 重新应用补丁（例如误还原后）
1. 双击运行 `应用补丁.ps1`（或 PowerShell 执行 `powershell -ExecutionPolicy Bypass -File "应用补丁.ps1"`）
2. 脚本会自动结束正在运行的 Sparrow、备份原版、安装汉化镜像
3. 启动 Sparrow.exe

### 还原英文版
1. 双击运行 `还原.ps1`
2. 脚本用 `backup\modules.original` 恢复原始镜像

## 五、还原后可再次汉化 / 增量翻译说明

若想在字典中追加新翻译，可编辑 `patch\翻译字典\java_trans_all.json`
（`"英文原文": "中文译文"` 结构），然后按序运行：

1. `脚本\apply_java_trans.py`（应用 Java 字面量翻译，幂等）
2. `脚本\rebuild_jimage.py`（重建汉化镜像）
3. `应用补丁.ps1`（安装新镜像）

> 注意：涉及与外部值比较的字符串（见翻译字典约束）不可翻译，以免破坏
> 过滤、排序、协议判断等功能。

## 六、关于目录空间的说明

汉化过程产生的临时工作文件已清理，`C:\Software\Sparrow` 占用约 0.8 GB，
其中约一半为汉化工作区（`_work`、`_jdk`）：

| 目录 | 占用 | 说明 |
|---|---|---|
| `runtime`、`app`、`Sparrow.exe` | ~220 MB | 程序本体（含已装汉化镜像） |
| `中文补丁` | ~176 MB | 交付物：补丁镜像 89 MB + 原始备份 85 MB + 字典脚本 |
| `_work\extracted` | ~185 MB | 汉化素材源（解包后的类与界面文件），供未来增量翻译 |
| `_jdk` | ~304 MB | JDK 25 工具链（jimage/javap），供重建与验证 |
> 如确定不再进行增量翻译，可删除 `_work\extracted` 与 `_jdk`（共省约 490 MB），
> 汉化结果与还原能力不受影响；日后如需增量翻译，重新下载 JDK 25 后按第五节流程操作即可。

## 七、已知限制

- 硬件卡（Satochip / Keycard / Tapsigner）底层协议错误、Electrum / Bitcoin Core 服务端日志消息、
  Tor 底层错误保留英文（见第一节说明）。这些串多出现在日志或协议异常场景，保留英文便于对照
  上游文档排查，不译不影响界面使用。
- 汇率模块因当前网络不可达，日志有 WARN（属正常，不影响功能）。
